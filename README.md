# Player_Movement_Analysis_in_NFL-Big_Data_Bowl_2026
Developed a Pursuit Efficiency Index (PEI) to evaluate NFL defensive players using 18 weeks of tracking data. Built a 0–1 metric combining schedule, lateral, and radial errors to benchmark pursuit efficiency, with visualizations to communicate insights effectively.
